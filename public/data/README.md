# Geography attribution
Indonesia geometry extracted, without neighboring countries, from Natural Earth 1:10m Admin 0 Countries.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson
Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
Modern coastlines and administrative footprint; not a reconstruction of historical coastlines or political boundaries.
